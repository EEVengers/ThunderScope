# ThunderScope
Low-Cost Four Channel 1GSPS Oscilloscope using Thunderbolt/USB4 to stream data to PC for processing and display. 

Join our [discord](https://discord.com/invite/pds7k3WrpK), we are now at #thunderscope:matrix.org on matrix or #thunderscope:libera.chat on IRC as well!

All of our latest documentation is on our [docs site](https://docs.eevengers.com/ThunderScope/latest/index.html)

You can get the hardware through our [crowdsupply page](https://www.crowdsupply.com/eevengers/thunderscope)!
