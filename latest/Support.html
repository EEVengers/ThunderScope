Support#

We try our best to keep the documentation updated with everything you need to use ThunderScope, so if you are having any problems please look around the docs site to see if your question is already answered here. If it is not, please go through one of the support channels listed below in order of priority.

GitHub Issues#

Look through our support related GitHub issues. If there is already an issue similar to yours, please comment on it. If there is not, please open a new issue. We will triage the issue and do our best to solve it for you.

This is the method we most prefer when dealing with support issues as it centralizes them to a place that is openly readable without an account. By commenting on existing issues, it enables us to prioritize the issues that are most common and opening new issues helps future users that may encounter your same issue.

Discord Community#

The ThunderScope discord is the ideal place for discussing ThunderScope, how you are using it, things you might want to use it for, and open source test equipment in general.

In short, if you want to talk shop or get some technical advice, this is where you should go. If you suspect you are encountering a bug, it is best to file a GitHub issue instead. Anything serious is easily lost on discord and should go somewhere more openly searchable.

Email Support#

If you wish to have your issue addressed privately, you may send us an email through the form provided by Crowd Supply. Please note that this email is monitored by only one person and replies are on a best-effort basis.

Problems With Your Order?#

We do not handle shipping or payment when you buy ThunderScope. If you have any problems with your order, please contact the distributor that you have placed the order with.
